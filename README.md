# RetroVault

RetroVault is a Linux-first retro gaming management platform built around RetroArch.

The goal of RetroVault is to provide a complete ecosystem for managing, organizing, customizing, and launching retro game collections.

## Current Features

- ROM library scanning
- Multiple library sources
- Platform detection
- RetroArch core mapping
- Library building system
- Game browsing interface
- Game details panel

## Planned Features

- RVDB (RetroVault Database)
- Artwork management
- Metadata management
- Overlay manager
- Shader manager
- Launch profiles
- Collection health reports
- Network library support

## Requirements

- Linux
- Python 3.12+
- RetroArch
